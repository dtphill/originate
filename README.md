# Galaxias — film and sound

A portable media page for David Phillips' application, with the supplied development reel artwork and nine edited music excerpts.

The complete website lives in `public/`. Copy that folder's contents to any static web server to publish it. It uses plain HTML, CSS and JavaScript, with no application backend.

Track order: Rain, Frog, Flood, Fluvial, Storm, Between the Rocks, Murk, Tiny Legs, Mechano-receptors.

The film button opens the existing Google Drive video. The large video source is not included in this repository.

Cloudflare deployment configuration and instructions are being prepared alongside the website files.
